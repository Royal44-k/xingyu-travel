# 行屿旅行 · XINGYU

行屿旅行是一个面向国内自由行场景的旅行服务应用原型。它将透明比价、攻略发现、攻略转行程、旅行搭子、AI 助手与行程守护串成一条可在浏览器内完成的体验闭环。

- 在线地址：[xingyu-travel.vercel.app](https://xingyu-travel.vercel.app)
- 源码仓库：[Royal44-k/xingyu-travel](https://github.com/Royal44-k/xingyu-travel)
- 技术栈：Next.js 16、React 19、TypeScript、Zustand、Motion、Vitest、Playwright

> 本项目是可交互的产品演示与前端原型。比价、搭子、AI、风控与守护均使用受控的沙箱数据或浏览器本地状态；不提供真实出票、支付、退款、身份核验或紧急救援调度服务。

## 主要能力

### 透明比价

首页的机票、酒店、门票入口会进入统一比价页。报价以含税总价、退改条件、供应商可信度、更新时间与解释信息展示；点击合作方入口前会出现外部跳转确认。

### 灵感广场与攻略转行程

在“灵感广场”浏览大理、桂林、川西、三亚、杭州、南京、上海与贵州等目的地攻略。每篇详情页提供四张沉浸式图片、地点卡片、行程节点与预算信息；点击“转为行程”后，草稿会被保存并在“我的行程”中继续编辑。

### 我的行程与守护

行程工作台支持调整节点、选择备选方案、发布搭子意愿与开启行程守护。守护页仅对演示数据中已支持风险事件的行程开放，并明确展示 Plan A/B/C 与本地保存状态。

### 旅行搭子

搭子页以成年、认证、日期、目的地、容量、拉黑关系与安全状态等规则进行硬过滤，再解释日期、预算与节奏等匹配因素。聊天、联系方式确认、举报、拉黑与平安签到均为本地演示流程。

### AI 旅行助手

助手默认使用受控回答模板，返回风险等级、备选方案、证据、新鲜度与是否需要人工帮助。即使配置了外部模型，也不应将它当作实时救援、医疗、法律或订单执行系统。

### 个人中心

个人中心汇总兴趣标签、喜欢的攻略、收藏报价、降价提醒与安全状态。兴趣标签可清空后重新选择；点赞、报价收藏和行程保存均会反映在相应列表中。

## 浏览器本地数据

本项目采用“浏览器本地持久化完整闭环”。下列体验主要使用当前浏览器的 Local Storage：

- 兴趣标签与个性化偏好
- 喜欢的攻略、收藏报价与降价提醒
- 行程草稿、行程编辑、守护方案与搭子意愿
- 搭子演示状态、聊天安全状态与个人中心汇总

因此，换浏览器、无痕窗口、清除站点数据或更换设备后，相关演示数据会重置。请勿在本地演示表单填写真实证件、银行卡、精确行踪或其他敏感个人信息。

## 本地运行

### 前置条件

- Node.js `>= 24`
- pnpm `10`

### 安装与启动

```bash
pnpm install --frozen-lockfile
pnpm dev
```

开发服务器默认由 Next.js 启动。打开终端输出的本地地址即可访问应用。

### 常用命令

```bash
# 代码规范
pnpm lint
pnpm typecheck

# 单元与组件测试
pnpm test

# 浏览器端到端测试
pnpm test:e2e

# 生产构建
pnpm build

# 本地完整验证（不含 Playwright）
pnpm verify
```

Playwright 首次运行可能需要安装本机浏览器依赖；请按其终端提示完成安装。

## 环境变量

复制 `.env.example` 为 `.env.local` 后按需要配置：

```dotenv
AI_PROVIDER=mock
DASHSCOPE_API_KEY=
QWEN_PLUS_MODEL=
QWEN_MAX_MODEL=
QWEN_FLASH_MODEL=
```

默认 `AI_PROVIDER=mock`，适合本地演示与测试。若接入外部模型，请将密钥仅配置在本地安全环境或 Vercel 环境变量中，绝不要提交到仓库；并在上线前重新进行安全、事实性与提示注入评测。

## 项目边界与安全提示

- 演示报价不是可购买库存，供应商跳转不代表平台承担订单、支付或售后。
- 演示 AI 回答不可替代官方航司、景区、天气、医疗、公安或紧急服务信息。
- 搭子匹配不得基于宗教、民族、健康等敏感属性；精确实时位置不应公开。
- 生产接入真实供应商、身份服务或模型服务前，应完成合规评估、数据分级、最小必要授权与安全测试。
